Y sobre todo: decidió

El agente no ejecutó un guion — emitió criterio QA
Detectó una violación A11y real
El primer run salió 1/3 verde. Causa: SauceDemo /inventory.html tiene un select-name critical — el dropdown de orden no tiene label accesible. WCAG 2.1 AA fallido en el sitio bajo prueba.
→ A11y baked-in funciona, no es decoración
Corrigió selectors frágiles
El Style enforcer encontró 2 selectors crudos [data-test] en el spec de login generado por el Generator nativo y los reescribió a getByTestId, conforme al Style Contract del cliente.
→ convención de cliente enforced sobre el output
Juzgó la calidad y decidió no escalar
El Judge puntuó los 3 specs entre 0.90 y 0.96 sobre 7 ejes. 0 de 3 por debajo de 0.5 → el umbral "ask-first" (30%) no se superó. Decisión: exponer sin intervención humana.
→ veredicto numérico, no opinión
