## How to record

Seguir `demo/saucedemo/script.md`. Herramientas recomendadas:

- **OBS Studio** (gratis, cross-platform): https://obsproject.com/
- **ScreenToGif** (Windows): https://www.screentogif.com/
- **Microsoft PowerToys ScreenRuler + Snip & Sketch** para mostrar selectores con highlight.

## Encoding target

- Container: MP4
- Codec: H.264
- Resolution: 1920×1080
- FPS: 30
- Audio: AAC 128 kbps

## Convenciones del repo

- Los `*.mp4` están gitignored si pesan >50 MB. Para versiones >50 MB usar Git LFS o un link a almacenamiento externo.
- Los `*.gif` cortos (<5 MB) se versionan directos.
